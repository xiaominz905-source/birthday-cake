# A Little Universe for You 🌌

小陈的银河生日蛋糕互动网页项目。

## 项目状态

- GitHub Pages 自动部署工作流已配置。
- 网站入口文件 `index.html` 和相关资源上传后，会自动触发部署。
- 当前正在准备经过实际浏览器验收的生日蛋糕网页版本。

## 部署方式

项目使用 GitHub Actions 部署到 GitHub Pages：

1. 将网站入口 `index.html` 和所需资源提交到 `main` 分支。
2. GitHub Actions 自动构建并发布。
3. 部署完成后，在仓库 Settings → Pages 查看公开网址。

## 重要说明

正式网页需要保留 Three.js 模块及相关材质资源。不要用静态截图替代可旋转、可吹灭蜡烛的 3D 场景。
